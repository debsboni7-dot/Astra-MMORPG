# Unreal Engine scaffold retained for reference

ASTREA's selected native engine is now **Unity 6.3 LTS with URP**. The files in this folder are a legacy Unreal exploration scaffold and are not the active client project.

No Unreal Editor execution, packaging or runtime integration is claimed. New native client work belongs in ../unity/. The existing browser prototype remains available while the Unity client is brought up.

The Blender workbench now exports FBX for the Unity model importer. Keep the original Blender .blend as the editable source and validate the model's proportions, topology, materials, rig fit and performance before treating it as production art.
