# ASTREA terrain materials

The starter plains use locally bundled, mobile-optimized 512×512 WebP PBR maps. The starter plains use leafy grass. Forest floor, dirt paths and the rocky scatter currently reuse the dirt material as a lightweight fallback; dedicated biome materials remain a follow-up.

Sources: Poly Haven — `leafy_grass` and `dirt_floor` (1K JPG source maps, resized to 512×512 WebP for this project).

Source: https://polyhaven.com/license
Asset pages: https://polyhaven.com/a/leafy_grass and https://polyhaven.com/a/dirt_floor
Maps: diffuse/base color, OpenGL normal, roughness.
